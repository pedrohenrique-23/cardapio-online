# **Dev Burguer - Cardápio Online Interativo 🍔**

**Dev Burguer** é uma aplicação web interativa criada para gerenciar o cardápio de uma hamburgueria, oferecendo funcionalidades como controle de pedidos, integração com WhatsApp e notificações em tempo real. O projeto foi desenvolvido utilizando **HTML, CSS, JavaScript, Node.js** e **Tailwind**.

## 🛠️ **Tecnologias Utilizadas**
- **HTML**: Estruturação do conteúdo da página.
- **CSS**: Estilização do layout, com uso de **Tailwind CSS** para um design moderno e responsivo.
- **JavaScript**: Interatividade, incluindo o carrinho de compras e a validação de pedidos.
- **Node.js**: Backend para integração com a API do WhatsApp.
- **Toastify**: Notificações em tempo real para a experiência do usuário.

## 📋 **Funcionalidades**
- **Indicador de Status**: Mostra o status da hamburgueria (aberta/fechada) de acordo com o horário atual.
- **Carrinho de Compras**: Permite adicionar e gerenciar produtos.
- **Validação de Pedidos**: Validação de pedidos antes da finalização.
- **Integração com WhatsApp**: Facilita a comunicação direta com o cliente via WhatsApp.
- **Notificações em Tempo Real**: Notificações de atualizações de pedidos utilizando o **Toastify**.

## 🚀 **Como Rodar o Projeto**

1. Clone o repositório:
   ```bash
   git clone git@github.com:pedrohenrique-23/cardapio-online.git
   ```

2. Navegue até o diretório do projeto:
   ```bash
   cd dev-burguer
   ```

3. Instale as dependências:
   ```bash
   npm install
   ```

4. Execute a aplicação:
   ```bash
   npm start
   ```

5. Acesse a aplicação no seu navegador: `http://localhost:3000`
